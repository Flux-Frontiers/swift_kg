# Release Notes — v0.2.1

> Released: 2026-09-15

This is a documentation-only release: SwiftKG now has a citable archive.

## What changed

**A Zenodo concept DOI.** v0.2.0 minted the first archived release on Zenodo,
so there was nothing to cite before now. `CITATION.cff`, the README badge row,
and a new README citation section (APA and BibTeX) all point at the concept
DOI, `10.5281/zenodo.22759432`, which resolves to whichever version is newest
rather than pinning to this one. No code changed.

## Upgrading

Nothing to do. If you cite SwiftKG, use the DOI above.
